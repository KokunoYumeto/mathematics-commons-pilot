# Translation starter v2

This release contains one source-free starter for a mathematical translation project.

- Asset: `translation-starter-v2.zip`
- ZIP bytes: 11,181
- SHA-256: `90757C98A9E042209A3A86CEEC4F012EAF3B9B4EDF0667874A89EA617BC27315`
- Files: 12
- Represented source bytes: 21,128

The starter supports local repository-aware agents and hosted web agents. It asks for the work and the exact target language, locale, script, and orthographic standard before source acquisition. It then checks existing coverage and source eligibility.

The ZIP contains no textbook and no completed translation. Translation may begin only after immutable source identity, derivative permission, component rights, and baseline-build state are recorded.
