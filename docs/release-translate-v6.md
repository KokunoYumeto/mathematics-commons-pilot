Version 6 supersedes version 5 as the current starter. It distinguishes UNESCO's education-access figures from the separate UNESCO-UIS citation to a 48-country literacy study covering 96 alphabetic-script languages. The package preserves the exact 96 labels printed in that study's supplementary Table S1 as concrete suggestions, not a ranking or a fixed UNESCO translation-priority list.

The human-facing portal no longer foregrounds one reported production language. Unverified work-specific edition reports remain in the machine catalog so existing work is not silently erased or overwritten.

The package contains no textbook or completed translation. Every selected or newly proposed work still requires exact source, derivative-rights, component, editable-source, and baseline-build preflight before translation begins.
