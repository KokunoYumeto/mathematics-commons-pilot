Version 4 replaces opaque planning keys in the public chooser with semantic work keys. It separates reported Indonesian activity from verified language coverage, separates the older-manuscript archive from open-education suggestions, accepts additional openly licensed mathematical works, and records accurate UNESCO context without attributing an unsupported 96-language list.

The package contains no textbook or completed translation. Every selected or newly proposed work still requires exact source, derivative-rights, component, editable-source, and baseline-build preflight before translation begins.
