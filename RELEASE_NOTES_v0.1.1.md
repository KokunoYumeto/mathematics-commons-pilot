# Mathematics Commons Pilot v0.1.1

This is a citation-and-status follow-up to the frozen `v0.1.0` concept release. It does not add a mathematical result or change the scientific claims of that release.

## What changed

- citation metadata now distinguishes the all-versions concept DOI from immutable version DOIs;
- the README and status page now link the published `v0.1.0` record and describe the operational-MVP work as a separate review lane;
- the structural validator now excludes local `dist/` build and verification output from public-source scans; and
- the public project log and recovery record contain the verified release receipts.

## DOI meanings

- All versions / evolving project: `10.5281/zenodo.21828562`
- This `v0.1.1` deposit: `10.5281/zenodo.21830229`
- Frozen `v0.1.0` deposit: `10.5281/zenodo.21828563`

The concept DOI resolves to the latest published version. A version DOI identifies one immutable deposit and should be used when exact bytes matter.

## Scope and limitations

The project remains a concept plus a pilot under construction. It does not claim Leiden or IMU endorsement, journal peer review, an operational distributed network, or a solved open problem. The Research Packet schemas, validators, node handoff, fixtures, and first calibration set are being developed separately and are not represented as part of `v0.1.0`.

All Commons-originated material is dedicated under CC0 1.0, modulo pre-existing third-party copyright and other rights. Academic authorship, credit, priority, provenance, and responsibility remain separate scholarly obligations.
