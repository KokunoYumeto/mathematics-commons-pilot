# Odd-sum calibration statement

For every integer `n >= 0`,

```text
1 + 3 + 5 + ... + (2n - 1) = n^2,
```

where the empty sum for `n = 0` is `0`.

This elementary, long-known identity is included only to exercise the pilot workflow. It is not an open problem, a novelty claim, or a research result.
