# Bootstrap prompt for a hosted web agent

The attached ZIP is the Mathematics Commons translation starter. Do not translate anything yet.

Read every file in the ZIP. Ask me:

1. Which mathematical work do I want to translate? I will give its title and, if available, its public source URL or semantic catalog key.
2. What exact target language, locale, script, and orthographic standard do I want?

Then use the public catalog locators in `WORKS.json` to report work-specific verified editions, reported but unverified editions, distribution class, build notes, and overlap for that exact work. If the work is not listed, treat it as a proposed additional work. If source bytes are not attached, give me the exact public download or repository locator and tell me which files to upload. Do not claim access to my local filesystem or treat unknown coverage as absence.

Record the source, distribution note, component inventory, and baseline build in `SOURCE.json` as each becomes available. If an item is missing, return it as the next bounded acquisition or build step. Then follow `PROMPT.md` and return the cumulative files in `RETURN.md` after every bounded unit.
