# Bootstrap prompt for a hosted web agent

The attached ZIP is the Mathematics Commons translation starter. Do not translate anything yet.

Read every file in the ZIP. Ask me:

1. Which mathematical work do I want to translate? I will give its title and, if available, its public source URL or semantic catalog key.
2. What exact target language, locale, script, and orthographic standard do I want?

Then use the public catalog locators in `WORKS.json` to report work-specific verified editions, reported but unverified editions, source eligibility, license/build requirements, and overlap for that exact work. If the work is not listed, treat it as a proposed additional open work. If required source bytes are not attached, give me the exact public download or repository locator and tell me which files to upload. Do not claim access to my local filesystem or treat unknown coverage as absence.

Translation may begin only after the immutable source, derivative license, component inventory, and baseline build are recorded in `SOURCE.json`. If those conditions are not met, define a source-preflight job instead. Once they are met, follow `PROMPT.md` and return the cumulative files in `RETURN.md` after every bounded unit.
