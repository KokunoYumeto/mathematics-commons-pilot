# Start a translation

1. Decide whether you are using a local repository-aware agent or a hosted web agent.
2. Give that agent the corresponding bootstrap prompt: `LOCAL.md` or `WEB.md`.
3. Answer two required questions:
   - Which mathematical work do you want to translate? Give its title and, if available, its public source URL or semantic catalog key.
   - What exact target language, locale, script, and orthographic standard should the edition use?
4. Review the agent's report on work-specific editions, source availability, distribution class, and build notes.
5. Obtain the exact source archive or repository commit named by the agent (or use the source already held for the active work), record its byte identity and distribution note, and add it to the project.
6. Begin the source-order translation once the first bounded source unit is available; keep any missing source or build item as an explicit continuation cursor rather than silently guessing.

The listed works are non-exclusive starting points, not a closed curriculum. You may propose another mathematical work with a public source and a recorded distribution note. If a chosen work already has activity in the requested language, you may choose another language or declare an independently useful parallel edition. Do not overwrite another edition. Keep attribution, ShareAlike, non-commercial, and component notices exactly as recorded; a missing public packet is not a reason to call the workflow unrunnable.
