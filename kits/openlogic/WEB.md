# Hosted-project use

1. Create a new project in a capable hosted AI service.
2. Upload the complete ZIP without removing files.
3. Say: `Read START.md, verify the packet, and ask me the required questions.`
4. Answer the language, audience, overlap, and reviewer questions.
5. Keep the project on one bounded source-order unit at a time.
6. While a unit is in progress, say `continue`. After a unit is complete and the cumulative checkpoint is returned, say `next unit`.

Download every cumulative return. A chat transcript is not a substitute for the returned source, reader, state, manifest, and receipts.
