# Open Logic translation job

This packet contains one exact Open Logic source snapshot and the controls needed to produce a new standalone, monolingual edition. It contains no completed translation.

Start with [`START.md`](START.md). The first required user decision is the target language, locale, script, and written standard. Work only from `source/`; preserve it unchanged and place cumulative translated source under `target/`.

The packet is model- and vendor-neutral. It can be used with a local repository-aware agent or uploaded to a hosted project that accepts the ZIP.
