# Mathematics Commons Pilot v0.1.0

This is the first frozen concept release of the Mathematics Commons, a proposal for Leiden-led, AI-integrated mathematical work through bounded Research Packets and peer-to-peer review.

## Included

- the white-paper discussion draft;
- a clause-level Leiden alignment and durable requirements specification;
- a novice-readable GitHub pilot implementation guide;
- contribution, rights, citation, recovery, and agent-orientation policies;
- a privacy-by-default, proportionate-disclosure rule for every module and evidence bundle;
- structured public feedback forms and discussion entry points;
- a fail-closed public repository validator;
- a deterministic, exact-ref release archive and checksum builder; and
- a GitHub 2FA continuity runbook for human and automated workflows.

## Status and limitations

This is a concept proposal and pilot design. It is not a claim that the network is operational, that Leiden or the IMU endorses the project, that journal peer review has occurred, or that any open problem has been solved. The initial problem set, Research Packet schemas, reviewer pool, and live pilot remain future work.

The project's Leiden alignment is self-assessed. All Commons-originated material is dedicated under CC0 1.0, modulo pre-existing third-party copyright and other rights. Academic authorship, credit, priority, and responsibility remain separate scholarly obligations.
